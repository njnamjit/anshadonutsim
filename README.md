# 🍩 Ansha's Donut Crafting Simulator

**Ansha's Donut Crafting Simulator** เป็นเว็บแอปพลิเคชันเครื่องมือช่วยคำนวณและจำลองการคราฟต์โดนัทสำหรับเกม **Pokémon Legends: Z-A (Mega Dimension DLC)** ช่วยให้ผู้เล่นสามารถวางแผนการผสมส่วนผสม (เบอร์รี่และเนย) เพื่อคำนวณระดับดาว บูสต์เลเวล พลังงานโดนัท รสชาติ และเอฟเฟกต์พิเศษ (Potential Powers) ที่จะได้รับล่วงหน้าได้อย่างแม่นยำ

---

## ✨ คุณสมบัติหลัก (Features)

- 🧈 **ระบบเลือกเนย (Butter Selector):** รองรับเนยหลากหลายประเภทตั้งแต่ 3 ช่อง ถึง 8 ช่อง (เช่น Lumiosian Butter, Prismatic Butter, Hyperspace Butter)
- 🍓 **ฐานข้อมูลเบอร์รี่ครบถ้วน (Berry Database):** มีให้เลือกทั้งเบอร์รี่ธรรมดา (Regular Berries) และไฮเปอร์เบอร์รี่ (Hyper Berries) พร้อมแสดงค่าสเตตัสรสชาติแบบละเอียดยิบผ่าน Tooltip
- 📊 **คำนวณสเตตัสแบบเรียลไทม์ (Real-time Calculation):**
  - **Flavor Score & Multiplier:** คำนวณแต้มรสชาติและตัวคูณผลลัพธ์
  - **Star Rank (1-5 Stars):** คำนวณระดับดาวของโดนัทตาม Flavor Score
  - **Level Boost:** คำนวณระดับเลเวลที่จะได้รับเพิ่ม (สูงสุด Lv. 200)
  - **Donut Energy (kcal):** คำนวณพลังงานโดนัทสำหรับระยะเวลาในมิติ
  - **Flavor Breakdown:** กราฟแสดงสัดส่วนรสชาติ (Sweet, Spicy, Sour, Bitter, Fresh)
- 🍩 **ระบบสไปรท์และชื่อโดนัทไดนามิก (Dynamic Visuals & Names):** เปลี่ยนรูปภาพสไปรท์ของโดนัทและชื่อผสม (เช่น Meringue Donut, Curry Donut, Rainbow Donut) ตามรสชาติหลักและระดับดาวที่คำนวณได้
- ✨ **แสดงเอฟเฟกต์พิเศษ (Potential Powers):** แสดงบัฟ/เอฟเฟกต์ที่มีโอกาสได้รับพร้อมระดับพลัง (Lv. 1 - Lv. 3) ตามรสชาติเด่นของโดนัท
- 🌐 **รองรับ 2 ภาษา (Multi-language Support):** สามารถสลับการแสดงผลภาษาไทย (TH) และภาษาอังกฤษ (EN) ได้ทันที

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** HTML5, JavaScript (Vanilla ES6+)
- **Styling:** Tailwind CSS (via CDN), Custom CSS
- **Fonts & Icons:** Google Fonts (Prompt), Font Awesome 6
